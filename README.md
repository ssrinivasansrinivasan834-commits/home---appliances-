# Home Appliances Website

A clean and responsive web application for browsing home and kitchen appliances.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting:** GitHub Pages

## 🚀 Features
- **Product Showcase:** Displays washing machines, refrigerators, microwave ovens, etc.
- **Responsive Design:** Optimized for both mobile and desktop screens.
- **Easy Navigation:** User-friendly top menu and hero banner.
